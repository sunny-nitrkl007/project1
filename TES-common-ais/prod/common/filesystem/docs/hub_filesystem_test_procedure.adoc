== Test Platforms

The tests were written using the Boost Test Library.


== Test Setup

=== Build Instructions

1.  Clone the project repo:

  cd $GITHOME
  git clone git@arlgitgisp03.ecorp.cat.com:CATE_AIS/ais_app_template.git
  cd ais_app_template
  git checkout <TBD>

2.  Build the project. This is accomplished by executing the following command at the repository head folder:

  make project JOBS=12

3.  Set the environmental variables to the correct folder. After building the project, change the directory to the build-x86_64-linux-gnu and run changeCatEnvToHere.sh:

  cd build-x86_64-linux-gnu
  . ../changeCatEnvToHere.sh


== Test Execution

=== Boost “Unit Test” Scripts

Execute the unit tests by running the following commands:

  cd $CAT_DIR
  sudo -E bin/unit_test/hub_filesystem_unit_test --catch_system_errors=no
