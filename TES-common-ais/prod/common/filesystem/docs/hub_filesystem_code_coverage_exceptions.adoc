== Code Coverage Generation Procedure

1.  Build the project and get the additional files neeeded to determine the code coverage, using gcov. This is accomplished by executing the following command at the repository head folder:

  make project_gcov JOBS=12

2.  Set the environmental variables to the correct folder. After building the project, change the directory to the build-x86_64-linux-gnu and run changeCatEnvToHere.sh:

  cd build-x86_64-linux-gnu
  . changeCatEnvToHere.sh

3. Run all the tests for the desired module. A fast way to do this is using the generate_ad.py script:

  cd prod/machineCommon/content/util/test_utils
  python generate_ad.py 'hub_filesystem_test_procedure.ad'


4. In order to see the code coverage, run in ais_app_template folder:

  lcov --capture --directory $CAT_DIR/prod/coretech/hub/filesystem  --output-file ./coverage.info --no-external
  lcov --remove coverage.info -o coverage_filtered.info \
   '/usr/*'
  genhtml coverage_filtered.info --output-directory lcov
