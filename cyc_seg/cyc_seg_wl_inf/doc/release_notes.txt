==== CHANGE SUMMARY ====
|===============

|===============


==== DEPENDENCIES ====

Refer to the .../deps/ivy.xml for this repository.


==== CHANGE DESCRIPTION: ====

Output interface segment_active_segment_id added.  The output is used within Operator Coaching
on LWL machines. Change is made to the lib_feature/totalizer/Totalizer_00_lib.mdl 

Also added CycSeg C-handcode wrapper from ClearCase.  This required update to dependancies.

In ClearCase implementation the content from 'Interface' unit was compiled at application level. 
Where as the CycSeg wrapper handcode was provided in a separate library. With this release both of 
these are released with the MODELs binaries (wl_00-a, and wl_01-a).

For Linux platfroms the 'Interface' content will be picked up directly from the repo:
. interface/include
. interface/src

Repo: git@gitgis.ecorp.cat.com:es-ms-mach-prod/ss/cyc_seg_wl_inf.git
